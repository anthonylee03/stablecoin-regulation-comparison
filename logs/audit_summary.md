# 최종 보고서 독립 검수

검수일 2026-11-22. 대상은 `report/implications_final.md`와 그 인용 근거다. 기존 검수 파일은 열지 않았다. 분석 스크립트는 재실행하지 않았다. 원문은 저장본을 우선 사용했고 CASE-S03·04·05는 등록된 공식 URL에서 직접 확인했다.

## High

- **27행 · 출처와 충돌하는 미국 규제 상태.** “후속 규칙의 확정·시행 여부는 확인되지 않았다”는 문장 중 확정 여부가 틀렸다. 인용한 US-02는 OCC 최종규칙이며 DATES(72행)는 2027-01-18 시행을 명시한다. 해당 OCC 규칙의 확정과 기준일 현재 시행 전 상태를 구분해야 한다. US-01 §20의 법 시행 조건과도 구분이 필요하다.

## Med

- **7행 · 출처 없는 범위 확대.** “한국 사업 사례가 없어”는 전체 국내 시장에 사례가 없다는 뜻으로 읽힌다. 19행의 “사례 목록에 한국 핀테크 사업 사례가 없어”만 목록 대조로 확인된다(C02, C03 및 사례 목록). 7행의 예금토큰 근거는 13행의 C04·C07로 추적되지만 요약 문장 자체에는 연결 태그가 없다.
- **7·27행 · 과장 표현.** “가장 큰 쟁점” 및 “그다음”의 우선순위는 인가 경로와 준비금·상환 조문 비교만으로 입증되지 않는다. 27행은 작성자 판단임을 밝히지만 7행은 이를 사실처럼 요약한다.
- **27행 · 인과 단정으로 읽히는 문구.** “이 선택이 은행과 핀테크의 역할을 직접 가르므로”는 법문에서 확인되는 발행 자격과 시장에서 실제 형성될 역할을 연결한다. 제도상 신청 자격의 차이는 확인되지만 수탁·유통·제휴 역할이 어떻게 형성될지는 조건부다. 이 문장은 시계열 분석의 인과 주장과는 별개다.
- **23행 · 출처 위계.** Paxos 발행과 PayPal 유통은 CASE-S03 공식 출시 공지에서 확인된다. Venmo 송금에 직접 인용된 CASE-S05는 PayPal 공식 기술 블로그다. 해당 세부 주장에는 비블로그 공식 근거가 필요하므로 검수 신뢰도 low로 표시했다. [PayPal 공식 출시 공지](https://newsroom.paypal-corp.com/2023-08-07-PayPal-Launches-U-S-Dollar-Stablecoin) · [PayPal 기술 블로그](https://developer.paypal.com/community/blog/pyusd-stablecoin/)
- **5·11·15·23·27·29·36·38행 · 매트릭스 행 식별.** 한국 항목 키에 의원안 두 건과 정부 검토안이 함께 반환된다. 7개 물리 행에서 value와 source_quote가 UNVERIFIED다. 23행의 안도걸안 조항 등은 함께 명시한 직접 source_id로 확인된다.

## Low

- **13행 · 범위를 오해할 수 있는 표현.** “은행 인프라 안에서”는 현금 전환의 BDA 경로를 지칭할 때 맞는다(CASE-S09). JPMD의 전송은 Base 공개 체인과 호환 지갑을 이용한다(CASE-S08). 문장에서 전환과 전송 범위를 구분하면 해석이 명확해진다.
- **15행 · 적용 범위 생략.** EU EMT 비교의 “은행 별도계좌”에는 수취자금 최소 30%라는 제54조 범위가 생략됐다(EU-01). 별도계좌 예시 자체는 확인된다.
- **31행 · 표시 정밀도.** 부분·일반 적용의 창별 차이 6개는 저장된 결과와 일치한다. 두 행에서 표시된 변동률끼리 빼면 결과 차이 열과 0.01%p 차이가 있다. 저장된 출력의 차이 열로 일치 여부를 판단했다. 창 중첩·환율·신규 발행·공통 시장·USD 노출을 명시해 데이터의 인과 단정은 발견되지 않았다.

## 지정 항목과 집계

- 지정한 네 항목은 모두 PASS다. HSBC 인가·PayMe 출시(11행), 안도걸안 발행인 부담·보유 연동 혜택(23행), 두 의원안 인가 경로(27행), MiCA 창별 차이(31행)다. 27행의 미국 규제 설명은 별도 High다.
- 태그 49개(matrix 21, case 12, source 14, data 2)와 직접 source ID 26종을 확인했다. 매트릭스 물리 행은 29개로 PASS 22, PARTIAL 0, FAIL 7이다. 사례 수치 표본 3개와 본문 분석 수치 6개가 일치한다.
- **UNVERIFIED 매트릭스 value 7행.** KR-06 이자 1행과 정부 검토안(KR-04·05·14)의 발행 자격·준비금·이자·상환·은행 역할·인가 상태 6행. 이 7행의 인용 필드도 동일 상태다.
- **UNVERIFIED 시행일 18행.** 인용된 한국 매트릭스의 6개 항목에 연결되는 민병덕안·안도걸안·정부 검토안 각 6행. 위 7개 value 행과 중복된다. 양 의원안의 최신 공식 처리 상태도 인가 상태 행의 notes에 UNVERIFIED로 기록돼 있다.
- **본문 명시 UNVERIFIED 4항목.** 정부안 공식 전문·제출(3행), 양 의원안 확정 시행일(5행), Stripe 프리뷰 개별 요율(21행), PayPal 준비자산 수익 배분(23행). CASE-S03·05의 로컬 사본 필드는 UNVERIFIED지만 URL에서 직접 확인했다. 수치 표본의 CASE-S04도 URL에서 직접 확인했다.

## 오판 가능성이 큰 세 지점

1. 한국안 판정은 저장된 발의문·검토보고에 대한 것이다. 최신 심사·수정안까지 확인하려면 해당 공식 기록을 별도로 확보해야 한다.
2. EUR·USD 판정은 저장된 출력과 본문의 일치에 대한 것이다. 전체 원시 관측과 정밀도 처리의 정확성은 재현 실행으로 확인하지 않았다.
3. Venmo 항목의 low 판정은 인용된 문서의 출처 위계에 대한 것이다. 인용 목록 밖의 비블로그 공식 자료는 검수 범위에 포함하지 않았다.
